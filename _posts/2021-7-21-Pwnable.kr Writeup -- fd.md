> 題目 ssh fd@pwnable.kr -p2222 (pw:guest)



##  解題

### src

題目的 source code: 

```c
//fd.c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
char buf[32];
int main(int argc, char* argv[], char* envp[]){
        if(argc<2){
                printf("pass argv[1] a number\n");
                return 0;
        }
        int fd = atoi( argv[1] ) - 0x1234;
        int len = 0;
        len = read(fd, buf, 32);
        if(!strcmp("LETMEWIN\n", buf)){
                printf("good job :)\n");
                system("/bin/cat flag");
                exit(0);
        }
        printf("learn about Linux file IO\n");
        return 0;

}
```



### Some Basic Concepts of C

由於這是 pwnable.kr 的第一題， 所以在進入解題之前，我先稍微介紹一下 source code 裡一些 C 的基礎概念，對於剛入門 Pwn 的初學者或不熟悉 C 的人可以了解一下。



#### C Command Line Arguments


首先， 這個題目的程式是採用 command line argument 的輸入方式 ， 由命令行執行時直接將參數接在執行檔後面， 如: 

``` shell
./excutable argument1 argument2 ...
```



相信使用過很多命令行工具的人都不陌生。

而參數的設定，則是由 main 的參數來控制的， 由下面程式碼可以看到，main function 有 3 個參數分別為 argc, argv, envp。

```c
int main(int argc, char* argv[], char* envp[]){
```



三個 main 的參數大略意思如下:

|               |               argc                |          argv          |         envp         |
| :-----------: | :-------------------------------: | :--------------------: | :------------------: |
|     型態      |               整數                |  C Srtring 的指標陣列  | C Srtring 的指標陣列 |
| 大略<br/>意思 | 命令行參數的個數<br/>**''加一''** | 元素指向輸入的參數字串 | 元素指向環境變數字串 |



其中 main的第二個參數 argv， 儲存著各個在命行指令中，接在執行檔後面的參數字串的指標。

假設命令行是這樣的，

 ```shell
./excutable argument1 argument2 ... argumentN
 ```

在執行檔後面接了 N 個字串分別為 argument1, argument2, ...... , argumentN 。

則 argv[1] 會指到 argument1、argv[2] 會指到 argument2、......、argv[N] 會指到 argumentN。



那麼就會有人疑問啦，argv[0] 又是什麼東西? 

沒別的，就是該程式的名字啦。確實挺莫名的，但是知道就不會忘了。其實 main 的第一個參數 **argc 真正的意義就是 argv 的元素個數。** 所以 argc 要減一才會是命令行中的參數個數。更多關於 argc 與 argv的資訊， 可以參考這篇  [C - Command Line Arguments](https://www.tutorialspoint.com/cprogramming/c_command_line_arguments.htm)。

至於 envp，則是為了省去每次輸入一堆參數的麻煩，直接把環境變數拿來用，更多詳細資訊可參考這篇  [Environment variables](http://www.crasseux.com/books/ctutorial/Environment-variables.html)。



所以看到原始碼

```c
if(argc<2){
	printf("pass argv[1] a number\n");
    return 0;
}
```

當 argc 小於 2 時，也就是在命令行中沒有後綴參數，程式就結束了。

而  ```int fd = atoi( argv[1] ) - 0x1234;``` 就是將傳進的第一個參數字串當成數字轉成整數，再減掉 0x1234。

也就是說，題目要我們後綴的參數應為數字。





#### File Descriptor

根據 [維基百科](https://zh.wikipedia.org/wiki/%E6%96%87%E4%BB%B6%E6%8F%8F%E8%BF%B0%E7%AC%A6)，

> 檔案描述符(File Descriptor) 在形式上是一個**非負整數**。實際上，它是一個索引值，指向核心為每一個行程所維護的該行程打開檔案的記錄表。當程式打開一個現有檔案或者建立一個新檔案時，核心向行程返回一個檔案描述符。

關於檔案的所有操作，如寫入 write() 或讀取 read() 都需要檔案描述符(以下稱 fd) 來辨識要操作的檔案。

然而，在一般的情況下，每個行程至少會開啟三個 fd, 分別為 0, 1, 2:

|  fd  |       0        |       1        |       2        |
| :--: | :------------: | :------------: | :------------: |
| 名稱 | Standard input | Standard outut | Standard error |

這就是這題的解題關鍵!



### The Idea

read() 的使用方法如下:

```c 
read(fd, buffer, n); 
```

當 fd 為 0 時，就變成從標準輸入裡讀 n byte 到 buffer 裡。

[File Descriptor 0](https://stackoverflow.com/questions/24136545/file-descriptor-0) 這篇 stackoverflow 解答提到，當 fd 為 0 時，會等待使用者輸入， 直到輸入了 n byte 的資料或者遇到跳行、EOF 或 ```Ctrl``` +```D```。



所以原始碼裡，

```c
len = read(fd, buf, 32);
if(!strcmp("LETMEWIN\n", buf)){
                printf("good job :)\n");
                system("/bin/cat flag");
                exit(0);
        }

```

我們只要讓 fd 的值為 0 ，就可以任意更改 buf 的內容。 

而程式所做的事，是比對 ```"LETMEWIN\n"``` 與 buf ，如果一樣，就能拿到 flag。

> ⚠ **注意** : 如果兩個字串一樣，strcmp 會回傳0；不一樣則回傳非0，見  [C strcmp()](https://www.programiz.com/c-programming/library-function/string.h/strcmp) 。



### The Solution

由剛才介紹 C commamd line arguments 的地方提到， 

題目中 fd 就是第一個參數減 0x1234 ，也就是減掉 4660

```c
int fd = atoi( argv[1] ) - 0x1234;
```

所以我們只要在命令行執行程式時，後綴 4660

```shell
fd@pwnable:~$ ./fd 4660
LETMEWIN
```

程式就會停住等待我們輸入東西，這時候再輸入 ```LETMEWIN``` 按 ```Enter```，就拿到 flag 了 !!!

> ⚠ **注意** : pwnable.kr  的 flag 的形式有時不像一般 CTF 為 "anything{anything}" ，有時是一段沒有特定格式的字串或 [leet](https://en.wikipedia.org/wiki/Leet)。不要已經拿到 flag 還不知道是 flag (對，就是我 XD
